This thesis asks how reliably current open-weights, locally hosted document
\acp{VLM} can read German business-to-business invoices into a legally meaningful
structured form, under the professional-confidentiality constraints that make
sending client documents to external cloud services problematic for German tax
advisors. A two-stage local pipeline is built and measured: a document \ac{VLM}
transcribes the page, and a language model maps the transcript onto the
\ac{EN}~16931 field set. Evaluation uses sealed training and validation splits, a
field-weighted metric suite derived from German invoicing law, and an attribution
study that separates reading errors from structuring errors.
